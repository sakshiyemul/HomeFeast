🍱 HomeFeast - Homemade Food Delivery Web Application

HomeFeast is a full-stack Homemade Food Delivery web application that connects users with trusted home cooks for fresh, hygienic, and affordable homemade meals. The platform also includes dedicated Cook and Admin panels for complete management of food services.
✨ Features
👤 User Side

 User Registration & Login
 Browse Verified Home Cooks
 View Cook Profiles & Menus
 Place Food Orders
 Subscribe to Meal Plans
 Give Ratings & Reviews
 Responsive & Modern UI

👩‍🍳 Cook Panel

 Cook Login Authentication
 Create & Manage Cook Profile
 Add / Edit / Delete Menu Items
 Manage Meal Plans
 View Customer Orders
 Update Food Availability

🛠️ Admin Panel

 Admin Login Authentication
 Approve / Reject Cooks
 Manage Categories & Cuisines
 Manage Users & Orders
 Handle Complaints & Reviews
 Dashboard Analytics
